# 单通道 EEG 去伪影实验日志

**整理日期 2026-11-16** · 本地训练记录覆盖 2026-05 至 2026-11-11。研究主线是测量有限未来信息能换回多少去伪影精度，以及对应模型在 Raspberry Pi 5 上的实时处理能力。

[数据索引与原始记录](experiment-log-2026-11-16-index.md)逐条列出训练、EEG-IO、设备测量、诊断和过程日志。本日志基于工作区已保存的数据计算，覆盖旧协议和探索性试验。原始记录留在原位置。

## 3. EEG-IO · 20 名被试的真实录波

数据目录有 20 份 EEG-IO 室内录波。EEG-VV 和 EEG-VR 各有 13 份录波，本次未发现对应的已存评估结果。[真实数据说明](../README.md#eeg-io)

EEG-IO v2 的幅度比来自眨眼锁定平均波形，接近 1 表示残余眨眼相对背景更弱。背景 RMSE 比较输出与预处理后输入，录波没有配对的干净真值。计数减少率使用输入、输出各自的六倍平均绝对幅度阈值，并与人工标签匹配。未达到阈值的标注、各被试分母和背景衰减都会影响计数。各表主指标取被试中位数，汇总峰数另列。[指标实现](../eegio_eval.py)

### 3.1 常规回放与背景保留

seed 54、67 的 TCN 与 TCN+SE 同用 250 Hz、ChannelNorm、BOTH、H=4 和因果滤波。SE 的幅度比、背景 RMSE 在两组均下降，但输出匹配峰总数略增，眨眼区成对抑制功率变化方向也不同。当前证据支持这两组 SE 的相对背景和幅度比折中，绝对眨眼抑制的结果随指标变化。[seed 54 TCN](../eegio_tests/eegio_20261105_164435.json) · [seed 67 TCN](../eegio_tests/eegio_20261106_123431.json) · [SE](../eegio_tests/eegio_20261104_162544.json)

| 种子 | 幅度比 TCN → SE | 背景 RMSE µV | 计数减少率 % | 输出匹配峰 |
| --- | ---: | ---: | ---: | ---: |
| 54 | 4.34 → 3.99 | 20.59 → 20.22 | 91.49 → 87.87 | 36 → 39 |
| 67 | 4.69 → 3.45 | 20.45 → 20.05 | 90.10 → 91.49 | 29 → 31 |

三个已归档的诊断补充了对照条件：

- **早期 batchnorm TCN。** 在 20 名被试上输入→输出幅度比 15.48→4.96，匹配峰 287→85。背景输出／输入 RMS 中位数为 0.309，扩大保护区至每个标注前后 1.5 s 后为 0.489。128 段独立干净输入仍有 0.505 的 RRMSE。训练总是加入较强伪影，是背景衰减的一个有证据支持的解释，干净和高 SNR 训练的作用仍待受控重训。[原诊断](../../diagnostics/eegio_20261105/EEG-IO%E8%AF%8A%E6%96%AD%E6%8A%A5%E5%91%8A.md)
- **SE 的早期跨配置对照。** 两模型实际干净测试池取交集得到 66 段，TCN→SE 的干净输入 RRMSE 由 0.481 降至 0.412，65/66 段改善。比较同时改变了 seed、内部归一化与 SE。[原诊断](../../diagnostics/eegio_20261105_se/TCN-SE%E7%BB%93%E6%9E%9C%E5%88%86%E6%9E%90.md)
- **EOG-only 与 BOTH。** seed 54 同为 SE、ChannelNorm、250 Hz。510 个同源合成 EOG 对中的 RRMSE 为 0.466 与 0.539，真实 EEG-IO 幅度比为 5.44 与 3.99、计数减少率为 66.67% 与 87.87%，背景 RMSE 为 18.28 与 20.22 µV。BOTH 混合同时改变训练伪影种类和总噪声，尚未按最终 SNR 控制二者。[原诊断](../../diagnostics/eegio_20261105_eog/EOG%E4%B8%8EBOTH%E8%AE%AD%E7%BB%83%E6%AF%94%E8%BE%83.md)
